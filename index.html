Welcome! Setup Required

To access the full Bible, you need a free API key from API.Bible. It takes 2 minutes to set up:

1.

Go to scripture.api.bible

Click "Get Started" in the top right

2.

Create a free account

Sign up with your email (no credit card needed)

3.

Go to "My Apps" and create a new app

Give it any name (like "Bible Study")

4.

Copy your API key

It will look like a long string of letters and numbers

5.

Paste it below and click "Save"

Your API key is stored locally in your browser and never sent to anyone except API.Bible.
